An AI Browser Agent
That Respects Your Privacy.

NAVIGATOR sees the web the way you do — understanding every screen, filling every form, executing every workflow — while credentials and PII are redacted on your machine before any model sees them. Screenshots stay local unless you explicitly opt in. No sessions recorded. No training on your life.

01 · The Problem

Browser agents today see everything — and send it away.

Screenshots leave the loop

Most vision-based agents upload full page captures to cloud LLMs. Your banking pages, health portals and inbox ride along.

Agents are screen-blind

Today they guess. Relying on brittle DOM selectors, they break the moment a UI shifts — and they can't read what a human sees.

Repetitive work stays manual

Filing the same form, re-uploading the same invoice, checking the same dashboard — with no trustworthy agent to automate them.

02 · The Solution

Vision-grade understanding.
Local-first trust.

  • Visual Understanding

    Live DOM elements, accessibility roles and bounding boxes are mapped into a spatial view. Optional remote vision is off unless an operator opts in.

  • Privacy Preservation

    A local, fail-closed redaction layer strips credentials, cards, tokens and URL secrets before any planner sees a payload. If redaction fails, the task stops.

  • Task Automation

    Natural-language missions ("renew my passport slot weekly") compiled into supervised, schema-validated browser actions.

03 · Workflow

From mission to completed task in four steps.

  1. 01

    Tell the Mission

    Type or speak the goal. The intent engine parses it into checkable sub-tasks.

  2. 02

    See the Screen

    The observer maps interactive elements, accessible names and bounding boxes — with screenshot grounding available as an optional fallback.

  3. 03

    Act Under Supervision

    Actions run in your own browser through a Manifest V3 extension, with a live approval gate for sensitive steps.

  4. 04

    Report, Locally

    Every run streams into a local timeline with redacted evidence; bounded task records are pruned automatically.

04 · Features

Built like a privacy product, not a demo.

Local-First Vision

Screenshots stay on your device by default. Remote vision is opt-in, capped at 4 MB, raster-only, and suppressed whenever a sensitive field is on screen.

PII Sentinel

Before any planner call, a local redaction layer masks passwords, card numbers, SSNs, emails, API keys and URL secrets — and fails closed if it cannot.

Auditable Run Timeline

Every step streams to the local console with redacted evidence, while bounded in-memory task records are pruned automatically.

Adaptive UI Resilience

DOM-first targeting with accessible-name matching and a DPR-normalized coordinate fallback survives layout shifts that break selector-only agents.

05 · Use Cases

Where NAVIGATOR earns its clearance.

Govt Portals & Passports

Watches appointment availability, auto-fills fields with your locally-saved profile, books the slot in seconds.

Banking & Finance

Reconciles monthly statements, pays scheduled bills, and flags anomalies — with local redaction and an approval gate before any sensitive action.

Healthcare

Refills prescriptions and fetches reports from portals that never seem to work the same way twice.

E-Commerce Ops

Re-orders stock from vendor portals, tracks dispatch status, escalates delays into your inbox.

Student Administration

Timetable sync, fee reminders, form resubmission — the routine nobody automates, done quietly off-hours.

Accessibility Ally

For users with motor or vision impairments, NAVIGATOR completes fiddly flows by voice — with credentials redacted from the run log.
