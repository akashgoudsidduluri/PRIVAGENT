LLM Provider Settings

The API key is stored only in the backend process (never sent back to this page or written to task history). Model changes apply to the next mission without a restart.

Saved Credentials (Vault)

Credentials are stored encrypted on this machine and are never shown again — not even to you. The agent only ever sees a placeholder like {{CREDENTIAL:example.com:login:personal}}. One-time codes (OTP / TOTP) are never stored: the agent hands the browser to you instead.

Saved credentials

    You can also use Chrome's built-in password manager / autofill instead — the agent will never ask for a password in chat.

    Long-term Memory

    The agent remembers durable facts about you, reusable skills it has learned, and reference files — all stored encrypted on this machine. Memory is only ever written by you, or from a finished task's confirmed outcomes after you approve it here. Page content can never write memory. Facts and skills are recalled into the planner prompt (top 5 facts / 800 chars, top 2 skills); files are never sent wholesale — the planner sees a short summary only.
